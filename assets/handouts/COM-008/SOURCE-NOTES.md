# COM-008 screen reference

The project owner supplied ten Android UV-PRO app captures and authorized their use, cropping, and exclusion in the project conversation on October 9, 2026.

The selected illustration adapts capture 6 (channel edit) and capture 9 (device settings). The chat images were visible but were not mounted as downloadable original files in this workspace. An image tool produced the combined reference from those images. It is an illustrated adaptation, not a pixel-identical crop. The caption and asset manifest identify it accordingly. The generated original is retained at `/workspace/generated_images/exec-d2f364f0-3208-4e65-ab0a-972ad52e09d6.png` in this environment; the repository uses a Base64-encoded copy.

The field labels and shown values were compared visually against the supplied captures. The adaptation omits personal profiles, maps, phone status bars, and unrelated settings. The illustration's right-hand heading is explanatory; the original device-settings crop did not show a page heading. Do not use the illustration as evidence of that header's exact wording.

The original edit capture shows TX `467.387506 MHz`, whereas the project owner confirmed the programming target as `467.38750 MHz`. The handout explicitly tells users to enter the confirmed target. Both DCS fields display `DCS-331N/465I`; the instructions identify the entry containing `331N` without treating `465I` as a second independent setting.

The captures show `LHH FW` as the memory name, `High` as TX power, and `12.5KHz` as bandwidth. The guide uses `Heights 6` as the descriptive memory name and explains that `LHH FW` is the captured example label. Power and bandwidth remain subject to the radio lead's channel authorization. The supplied settings screen reports firmware `0.9.3`; the app version is not visible, so it is not inferred.

The guide still requires the repository's editor and subject-matter review and a physical radio commissioning check before publication. Generated PDF/layout validation does not demonstrate programming on a physical UV-PRO.
